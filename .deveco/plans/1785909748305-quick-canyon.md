## 3. 当前多人调用链

```
用户发送消息
→ GroupChatViewModel.sendUserMessage()
  → GroupChatRuntimeService.startRound(plan, callbacks)
    → configSnapshot = modelService.getCurrentConfig()  [一次/轮]
    → roundCoordinator.beginGeneration(plan)              [创建operationId]
    → while (currentCtx !== null) {
        executeSpeaker(currentCtx, plan, callbacks)       [每角色一次]
          ├─ messageService.listMessages(chatId)          [重新读DB]
          ├─ messageService.appendStreamingAssistantMessage(chatId, characterId, roundId)
          ├─ SpeakerContext 创建                           [新实例]
          ├─ promptAssembler.assemble(context)             [新Prompt]
          │   ├─ characterService.getById(speakerCharacterId)  [当前角色卡]
          │   ├─ loadParticipantNames(ids)                     [仅名字]
          │   ├─ lorebookService.getCurrentLorebook()          [世界书]
          │   ├─ promptPresetService.getCurrentPreset()        [预设]
          │   ├─ modelService.getCurrentConfig()               [配置]
          │   ├─ convertHistoryMessages(messages, characterMap) [新数组]
          │   ├─ promptBuilder.build(context)                  [新PromptBuildResult]
          │   ├─ injectGroupConstraint()                       [新数组]
          │   └─ historyTrimmer.trim()                         [新数组]
          └─ streamForSpeaker(speakerCtx, promptResult, callbacks)
              ├─ currentStreamResolver = resolve               [替换]
              ├─ currentHandle = modelService.streamChatWithConfig(configSnapshot, messages, options, callbacks)
              │   └─ providerFactory.create(type)              [新Provider实例]
              │       └─ NEW OpenAIProvider + HttpStreamTransport
              │           └─ NEW OpenAIStreamSession
              │               └─ NEW RequestContext + HttpRequest
              └─ onComplete → cleanupSpeaker() → advanceSpeaker()
      }
    → tryGenerateNarration()  [可选,仅单目标轮]
    → roundCoordinator.markCompleted()
```

**共享的是什么**：configSnapshot（ProviderConfig，不可变引用）、plan（GroupRoundPlan，readonly）、roundCoordinator 状态

**每次重新创建的是什么**：SpeakerContext、Prompt 数组、ChatMessage[]、Provider 实例、HttpStreamTransport、OpenAIStreamSession、ChatRequest、ChatStreamCallbacks

**可能被复用的**：无。每个 speaker 从 DB 重读历史，重新构建完整 Prompt。
