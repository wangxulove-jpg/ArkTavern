# W2A2-WORLD-CHARACTER-PLACEMENT-UI 实施计划

## Goal

完成"世界地图 → 添加角色 → 选择放置方式 → 地图显示/未放置入口 → 实例详情操作"完整用户链路。

## Scope

- 添加角色时提供"暂不放置/放置到地点"选择
- 地图增加"未放置角色 · N"HUD 入口
- 实例详情页增加"调整位置/从地图撤下/从世界移除"分离操作
- "+"按钮重构为轻量菜单（添加角色/创建地点）
- 重复加入保护 UI
- 无地点世界处理

## Non-goals

- AI 角色分析/生成/移动
- Scene Launcher 新链
- Session UI / Runtime / Prompt / Provider / Streaming
- 拖动角色到地点
- PlayerProfile UI（拆到 W2A2-FIX-PLAYER-UI）
- 修改 Database Schema / Migration / DbHelper

## Current State And Constraints

### 已有基础设施
- **WorldStateService** 完整 API：`addCharacterToWorld`, `placeCharacter`, `placeCharacterAtLocation`, `unplaceCharacter`, `removeCharacterFromWorld`, `moveCharacter`, `forceMoveCharacter`
- **WorldCharacterManagePage** 已实现：候选角色列表、添加角色（无放置选择）、设置初始地点（单独按钮）
- **WorldCharacterInstanceDetailPage** 已实现：只读详情，"移动角色"按钮（已放置才启用）
- **WorldDetailPage** 已实现：沉浸式地图 + Billboard + "+"FAB → 直达角色管理页
- **WorldImmersiveMap** 组件：onAddCharacter 回调，Billboard 按 currentLocationId 分组

### 关键约束
- DATABASE_VERSION=23，本阶段不升级
- 生产文件上限 8
- 角色位置调整不修改 MapPlacement
- 不得调用 ModelService / Provider / Session
- Character 原始字段不得被世界操作修改
- placeCharacter 和 placeCharacterAtLocation 等价（都用 placeCharacter 即可）

### 数据库现有结构
- WorldCharacterInstance: currentLocationId TEXT NULL（NULL=未放置）
- WorldLocationMapPlacement: 地点节点的 XYZ 位置（与角色无关）

## Design

### 1. 添加角色流程重构

**当前**：`addCharacterToWorld()` → 创建 Instance（无地点）→ 用户单独点"设置初始地点"

**目标**：`addCharacterToWorld()` → 弹出确认 Overlay → 选择"暂不放置"或"放置到地点" → 如果选地点，立即 `placeCharacter()`

**实现**：在 WorldCharacterManagePage 中，点击"添加到世界"后弹出确认 dialog/sheet：
- 显示角色头像、名称、目标世界
- Radio: "暂不放置" / "放置到地点"
- 选"放置到地点"时展开地点列表（只显示当前 World 的 Active Location）
- 无地点时：默认选中"暂不放置"，显示说明文字，提供"创建地点"入口

### 2. "+"按钮重构

**当前**：`onAddCharacter` → 直接 `openCharacterManage()`

**目标**：点击"+"弹出轻量菜单：
- "添加角色" → `openCharacterManage()`
- "创建地点" → `openCreateLocation()`

**实现**：WorldDetailPage 中添加 `addMenuVisible: boolean` state，FAB 点击切换菜单显示。菜单用 CustomDialog 或 bindSheet 轻量实现。

### 3. 未放置角色 HUD

**当前**：无入口

**目标**：地图 Browse Mode 底部 HUD 增加"未放置角色 · N"，N=0 时隐藏

**实现**：
- WorldDetailPage 中从 `detail.characters` 过滤 `currentLocationId === ''` 的 Instance，计算 unplacedCount
- 在 bottomSummaryBar 上方或内部增加 unplaced 入口
- 点击打开未放置角色列表（bindSheet）
- 每项：头像、名称、[放置]、[查看]
- [放置] 打开 Location Selector（bindSheet 或 dialog）
- [查看] 导航到 WorldCharacterInstanceDetailPage

### 4. 实例详情页操作分离

**当前**：只有"移动角色"按钮（需已放置），无 unplace/remove

**目标**：
- "调整位置"（替代"移动角色"）：调用 `forceMoveCharacter`（不检查 Edge），文案用"调整位置"
- "从地图撤下"：调用 `unplaceCharacter`，二次确认
- "从世界移除"：在"更多"危险操作区，调用 `removeCharacterFromWorld`，二次确认

**实现**：
- ViewModel 增加 `unplaceCharacter()`, `adjustLocation()`, `removeFromWorld()` 方法
- 调用 WorldStateService 对应方法
- 操作成功后 increment `WORLD_DETAIL_REFRESH_TOKEN_KEY` 触发地图刷新

### 5. 重复加入保护

**当前**：ViewModel 的 candidates 过滤已加入角色

**目标**：如果 UI 状态过期（角色刚被其他路径加入），Service 层 UNIQUE 约束仍会阻止重复。UI 显示"已加入"而非"添加到世界"。

**实现**：WorldCharacterManagePage 的已加入列表显示"已加入"标签，点击跳转实例详情。candidates 列表在 loadSnapshot 时基于 `instanceRepository.findByWorldAndCharacter` 过滤。

### 6. 选择状态保护

- 实例被"从世界移除"后：若该实例是当前选中，清空 selectedInstanceId，关闭 Overlay
- 实例被"从地图撤下"后：保留选中，但地图高亮清除

### 7. 地图刷新机制

所有写入操作成功后 increment `WORLD_DETAIL_REFRESH_TOKEN_KEY`，触发 WorldDetailPage 的 `onRefreshTokenChange` → `loadDetail` → 重新计算 billboardData。

## Risks And Compatibility

1. **forceMoveCharacter 语义**：W2A2 用 `forceMoveCharacter` 实现"调整位置"，不检查 Edge。注释明确标注这是管理员位置调整，不是正式角色移动。
2. **WorldCharacterMovePage 共存**：该页面仍保留，但实例详情页的"调整位置"不再跳转 MovePage，而是直接在页内 Location Selector 完成。MovePage 保留给未来的正式移动（沿 Edge）。
3. **billboardData 计算不变**：recomputeBillboardData 仍按 currentLocationId 分组，未放置角色不出现。
4. **生产文件计数**：6 个生产文件 < 8 上限，留 2 个余量。
